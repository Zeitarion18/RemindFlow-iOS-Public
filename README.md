# RemindFlow — iOS reminders

Нативное приложение напоминаний для iPhone на **SwiftUI**, без подписки, облачного аккаунта и обязательного подключения к интернету. Данные задач хранятся локально на устройстве.

## Текущая версия: 0.2.2 (build 13)

- Создание и редактирование напоминаний: название, описание и единственное время события, в которое придёт основной сигнал.
- Необязательные предупреждения заранее (по умолчанию выключены) и настраиваемые интервалы автоповторов после события (по умолчанию выключены).
- Автоматические повторные сигналы, настраиваемый интервал, действия «Выполнено» и «Отложить».
- Повторяющиеся события: ежедневно, по выбранным дням недели, ежемесячно, ежегодно.
- Отдельные системные оповещения о наступлении события. Режим системного будильника на поддерживаемых версиях iOS (AlarmKit).
- Календарь событий, фильтры «Сегодня», «Завтра», «Неделя», «Все», просроченные задачи.
- Категории задач (готовые и пользовательские), цвета и иконки, четыре приоритета.
- Сортировка по дате, важности и названию, фильтрация по категории.
- Локальная история завершённых задач.
- Совместимость с маршрутизацией уведомлений на Apple Watch по правилам iOS/watchOS; отдельного watchOS-приложения нет.
- Русскоязычный интерфейс, тёмное оформление.

## Сборка IPA через GitHub Actions

1. Открой вкладку **Actions**.
2. Выбери workflow **Build RemindFlow iOS (unsigned IPA)**.
3. Нажми **Run workflow** на ветке `main`.
4. В завершившейся сборке скачай ZIP из раздела **Artifacts**.
5. Распакуй `RemindFlow-iOS-Preview-0.2.2-unsigned.ipa` и установи его через Sideloadly.

Workflow собирает **неподписанный IPA** на стандартном macOS-раннере GitHub. Подпись приложения при установке выполняется отдельно (например, через Sideloadly). Сборка на CI не подтверждает доставку уведомлений на физическое устройство; их нужно проверить на iPhone.

## Важно при обновлениях

- Основной идентификатор приложения: `app.remindflow.personal`. **Не меняй его** при обновлениях поверх старой установки.
- Идентификатор расширения AlarmKit: `app.remindflow.personal.alarmwidget`.
- Не удаляй установленное приложение перед обновлением, если хочешь сохранить локальные задачи. Сохранение данных также зависит от корректной переподписи.
- История и расписание задач хранятся в iOS UserDefaults на устройстве; в репозитории пользовательских напоминаний нет.
- Автоматические сборки из `main` запускаются при изменении исходников или workflow; ручная сборка доступна через `workflow_dispatch`.

## Безопасность публичного репозитория

Не добавляй в коммиты Apple ID, пароли, личные напоминания, сертификаты подписи, provisioning profiles, приватные ключи, токены GitHub и другие секреты. Для необходимых переменных CI используй **GitHub Actions Secrets** (но не публикуй их значения).

**Публичная видимость — не лицензия.** Пока в репозитории нет отдельного файла `LICENSE`, предоставление прав на использование, изменение и распространение исходников определяется применимым авторским правом.

## Техническая информация

- Swift / SwiftUI, XcodeGen, iOS 17+
- Для функций AlarmKit требуется поддерживаемая версия iOS
- Сборка: `.github/workflows/build-ios.yml`
- Конфигурация проекта: `project.yml`
- Модельные проверки: `tests/`

Проект разрабатывается как персональная офлайн-напоминалка без подписок.
